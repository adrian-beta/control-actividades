1. Explica la diferencia entre Git y GitHub.

Respuesta: La diferencia es que Github es la pagina donde tendremos guardados de manera online nuestro cambios y el Git es donde tenemos de manera local nuestros cambios

2. Explica para qué sirve .gitignore.

Respuesta: Sirve para evitar que al guardar nuestros cambios ignore ciertos documentos o carpetas que nosotros le indiquemos asi evitar problemas

3. Explica por qué .venv no debe almacenarse normalmente en GitHub.

Respuesta: No se debe almacenar ya que es el entorno virtual de nuestra computadora local

4. Explica para qué sirve requirements.txt.

Respuesta: Sirve para indicar que debemos instalar de requisitos una vez tengamos la copia de otro repositorio

5. Explica la diferencia entre Stage, Commit y Push.

Respuesta: Stage es para preparar los cambios que quieres realizar en el siguiente commit, Commit es para guardar los cambios de manera local y Push para enviar esos cambios a tu repositorio remoto

6. Explica por qué un repositorio puede tener varios commits antes de realizar un push.

Respuesta: Puedes realizar la cantidad de commits que necesites o en caso de olvidar modificar algo despues de hacer un commit solo que tienes que describir que fue lo que hiciste, pero esto normalmente para saber que cambios hiciste en cada commit para tener un orden y despues hacer el push para guardar esos cambios
